# Эмулятор Радио-86РК

Эмулятор компьютера «Радио-86РК» (процессор КР580ВМ80А) на чистом JavaScript,
с окном регистров и флагов, бегущим дизассемблером и пошаговым выполнением.

**Открывается двойным щелчком по `index.html`** — локальный сервер не нужен.

## Как запустить

Откройте `index.html` в браузере. Сразу заработает встроенная тестовая
программа-заглушка: она очищает экранную область и печатает строку. Кнопки
**Пуск / Пауза / Один шаг / Сброс** доступны сразу.

Чтобы получить настоящую машину, загрузите два образа кнопками в панели
«Образы» (или просто перетащите файлы в окно):

* **ПЗУ** — монитор, 2 КБ, размещается с адреса `F800`;
* **Знакогенератор** — 1 или 2 КБ, по 8 байт на знак, единичный бит = светящаяся точка.

Загруженные образы сохраняются в браузере (`localStorage`) и подхватываются при
следующем открытии страницы. Кнопка `✕` рядом с загрузчиком возвращает встроенные
заглушки. Образы в комплект не входят.

## Управление

| Клавиша | Значение на РК-86 |
|---|---|
| `Alt` или `Caps Lock` | переключатель РУС/ЛАТ (с фиксацией) |
| `Shift` | УС |
| `Ctrl` | СС |
| `Enter` | ВК |
| `Backspace` | ЗБ |
| стрелки, `Tab`, `Home` | соответствующие управляющие коды |

Клавиатура работает, когда фокус не стоит в поле ввода. Щелчок по строке
дизассемблера ставит или снимает точку останова.

## Структура

Каждый класс — отдельный файл, подключаются обычными тегами `<script>`
(модули ES браузер не грузит с `file://`, поэтому классы кладутся в глобальную
область — это осознанное решение ради запуска без сервера).

```
index.html                 разметка и порядок подключения
css/style.css              оформление
js/config/machines.js      описания машин: карта памяти, экран, клавиатура
js/core/I8080.js           процессор КР580ВМ80А, метод step()
js/core/Disassembler.js    таблица команд, разбор и форматирование
js/core/Bus.js             шина: ОЗУ, ПЗУ, устройства (таблица страниц)
js/devices/I8255.js        ВВ55 — параллельный интерфейс (клавиатура)
js/devices/I8275.js        ВГ75 — контроллер экрана, формат кадра и курсор
js/devices/I8257.js        ВТ57 — контроллер ПДП, адрес экранной области
js/devices/Keyboard.js     матрица 8x8 и перевод нажатий браузера
js/video/CharGen.js        знакогенератор: загрузка ПЗУ или резервный шрифт
js/video/Video.js          отрисовка знакомест в канву
js/roms/DemoROM.js         встроенная тестовая программа (заглушка)
js/Machine.js              сборка машины и ход времени
js/ui/Debugger.js          окна регистров, флагов и дизассемблера
js/ui/KeyboardPanel.js     диагностика клавиатуры: опрос, матрица, полярность
js/ui/UI.js                кнопки, загрузка файлов, ввод с клавиатуры
js/main.js                 точка входа
tests/cpu-test.js          проверка ядра в Node (node tests/cpu-test.js)
```

## Как это работает

**Процессор.** `I8080.step()` выполняет ровно одну команду и возвращает число
потраченных тактов. Такты взяты из документации; условные вызовы и возвраты
добавляют такты только когда условие выполнилось (`CALL` 11/17, `RET` 5/11).
Регулярные блоки (`MOV`, арифметика с регистром) декодируются по битовым полям,
остальное разобрано явным списком.

Недокументированные коды (`08`, `10`, `18`, `20`, `28`, `30`, `38`, `CB`, `D9`,
`DD`, `ED`, `FD`) не роняют эмулятор: они выводятся в консоль браузера с адресом
и счётчиком встреч, попадают в строку «Неизвестные коды» в интерфейсе и
выполняются как их фактический аналог на кристалле (`NOP`, `JMP`, `RET`, `CALL`).

**Время.** Кадр — `cpuFreq / 50` тактов. Процессор крутится, пока не выберет
бюджет кадра, затем перерисовывается экран. Бюджет считается по часам браузера,
поэтому на быстрой машине эмулятор не убегает вперёд; реальная скорость
показана в процентах от номинала.

**Видео.** Раз в кадр видеомодуль читает знакоместа из экранной области и
разворачивает их через знакогенератор в точки. Адрес области берётся из канала 2
контроллера ПДП — как на настоящей машине; пока монитор его не запрограммировал,
используется значение из конфигурации (`76D0`). Формат кадра запрашивается у
ВГ75, так что при смене машины трогать `Video.js` не нужно.

## Как добавить другую машину

Вся аппаратная специфика лежит в `js/config/machines.js`. Чтобы получить
Микрошу или Апогей, добавьте объект с описанием: области памяти (`regions`),
параметры экрана (`video`), знакогенератора (`charGen`) и клавиатуры
(`keyboard`) — и пункт в `<select id="machineSelect">`. Код эмулятора про
конкретные машины ничего не знает.

Заготовки для Микроши и Апогея уже есть, но пока повторяют карту РК-86 —
у Апогея изменён только адрес экранной области. Точные карты нужно уточнять.

## Если монитор не реагирует на клавиши

Раскладка клавиатурной матрицы (`buildAsciiMatrix` в `js/config/machines.js`)
задана как `код = 0x20 + строка * 8 + столбец`. Диапазон КОИ-7 `0x20..0x5F`
ровно укладывается в матрицу 8×8, но это инженерное допущение, а не выписка из
схемы: реальная разводка и полярность сигналов могут отличаться. Для разбора
есть панель **«Клавиатура»** — она отвечает на вопросы по порядку.

**1. Монитор вообще опрашивает клавиатуру?** Смотрите «Опросов матрицы» —
показания набираются примерно за секунду работы. Ноль означает, что монитор к
ВВ55 не обращается: дело не в раскладке, а в чём-то раньше по цепочке.

**2. Как он настроил ВВ55?** «Управляющее слово» и «Направления портов».
Ожидается `PA вых, PB вх, PC вх`. Если направления другие — опрос идёт по иной
схеме, чем предполагает `I8255.read()`.

**3. Попадает ли опрос в нужную строку?** Матрица 8×8 подсвечивает жёлтым
строку, которую монитор опрашивает прямо сейчас, и зелёным — нажатую клавишу.

**4. Не перепутана ли полярность?** Три флажка переключаются на ходу, всего
четыре осмысленных сочетания. Это самая частая причина полного молчания:
если строка выбирается единицей, а не нулём, опрос systematically промахивается
мимо нажатой клавиши.

Кнопка **«Журнал ВВ55 в консоль»** (или `emu.kbtrace()` в консоли браузера)
выводит последние 120 обращений к микросхеме — по ним видно точный протокол
опроса конкретного монитора.

Отделить неисправность тракта от несовпадения раскладки помогает встроенная
программа **«Тест клавиатуры»**: она опрашивает матрицу так же, как монитор, и
печатает код нажатой клавиши в левом верхнем углу экрана. Если здесь символы
появляются, а настоящий монитор молчит — тракт исправен, расходятся раскладка
или полярность.

## Проверка ядра

```
node tests/cpu-test.js
```

555 проверок: флаги арифметики и логики (включая особенности 8080 — `AC` при
вычитании и `ANA`), `DAA`, сдвиги, стек и `XTHL`, такты условных переходов,
исполнение всех 256 кодов операций, совпадение длин команд у процессора и
дизассемблера, работа клавиатурной матрицы через ВВ55 и чтение адреса экрана
из ВТ57.
